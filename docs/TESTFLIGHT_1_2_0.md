# v1.2.0 TestFlight 验收单

已有内测构建：iOS / macOS 1.2.0 (25)，功能源码基于 `908a8ca`（仅提高构建号）。该构建未包含 2026-09-29 的深链窗口复用修复，不能作为最终发布候选；新候选须使用更高构建号。上传和处理状态以 App Store Connect 及 Issue #7 当前记录为准。

本单只定义待执行步骤，不表示通过。每次执行记录平台、设备、系统版本、构建号、会员状态、实际结果和截图/录像链接。涉及购买的检查使用 Apple 沙盒测试账号；缓存测试不能替代真实购买/恢复/撤权。

## 免费收藏（#4）

1. 非会员打开颜色详情，收藏 A，再收藏另一月份的 B。打开收藏列表，确认顺序 B、A。
2. 选择 A，确认列表关闭、月份切至 A 所属月份、详情一致。
3. 在全屏信息栏取消 A，再添加 A，确认详情、全屏和列表状态一致，A 排在最前。
4. 退出 App 再打开，确认收藏仍在；在 Mac/iPad 多窗口中增删同一颜色，确认另一窗口同步。
5. 逐项取消本次测试新增的收藏，确认空态说明和“浏览颜色”均可用。保留用户原有收藏。

## 免费搜索与路由（#5）

1. 打开搜索；Mac 使用 ⌘F。空查询显示输入说明。
2. 分别查询 `銀朱`、`ぎんしゅ`、`五重塔`、` e34607 `、` #E34607 `，确认均包含 1 月 1 日「銀朱」，且无重复。
3. 查询 `not-a-color-xyz`，确认无结果提示；清空后恢复输入说明。多结果按日期排序。
4. 从搜索结果打开颜色，确认列表关闭、月份与详情一致。
5. 会员开启自动切换，打开搜索或收藏并等待超过五秒，颜色不得前进；关闭后重新等待完整五秒再前进。原本关闭的开关不得自动开启。
6. 在全屏、搜索和会员弹窗中分别打开 `jcolors://color/1_1`，确认清除遮挡、退出全屏、关闭自动切换，重复打开保持同一色。
7. 冷启动打开同一链接；快速连续打开两个有效颜色链接，最终显示最后一色。无效 ID/未知路径保持原选择。

## 每日色小组件（#6）

1. iPhone/iPad 主屏幕、Mac 系统宿主分别添加小号和中号，确认日期、色名、读音、HEX；中号额外显示典故。
2. 首次无缓存和非会员状态显示会员说明，点击进入现有会员页，不新增商品或付款入口。
3. 用已有终身会员恢复购买，等待系统刷新后确认 App 和 Widget 一致。沙盒购买、恢复、撤权分别记录实际结果；未发生刷新时区分系统调度延迟与缓存错误。
4. 在已确认会员后断网，重新打开 App/查看 Widget，确认保留最近有效权益；网络失败不得直接显示撤权。
5. 点击 Widget 后的颜色应对应点击时展示的条目，即使日期已变化也不得改为另一色。
6. 核对浅色、深色及系统着色，两种尺寸均无文字重叠、关键字段截断或不可读对比度。
7. 目录模型已覆盖跨年、闰日、DST 和时区；系统层仍需确认时区改变及日期变化后的实际刷新。记录请求与观察时间，不要求精确午夜刷新。
