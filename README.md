# JapaneseColors 日本传统色

[![Download_on_the_App_Store_Badge_CZ_RGB_blk_092917](assets/Download_on_the_App_Store_Badge_CNSC_RGB_blk_092917.svg)](https://apps.apple.com/app/id6462700791)  

日本人自古以来便擅于从各种日常之中获得色彩的灵感，并以纤细的视角赋予各种色彩独一无二的地位，并更进一步应用于绘画、工艺、织染甚至于文学与诗歌上。

于是我们可以从平安时代的女性们身上，看见和服的典雅配色；从日式庭园中，一窥白山绿水的调和色彩；在千年古城的堂奥里，看见代表昔日风华的金灿色泽。

「日本传统色」便是在长远的历史中一路累积而来。这里罗列了 365 种颜色，可以看到每种颜色背后的典故。

颜色数据均来源于 [暦生活](https://www.543life.com/)

**授权自limboy的网页版https://colors.limboy.me/**

所有颜色数据和图片均存储本地，浏览颜色无需联网。会员状态验证、购买与恢复购买需要联网。

## v1.2.0

- 收藏：在详情或全屏信息栏点击爱心，本机保存，按最近收藏排序。
- 全局搜索：搜索全部 365 色的色名、假名读音、典故或 HEX；Mac 支持 `⌘F`。
- 每日色小组件：终身会员可在 iPhone、iPad 和 Mac 添加小号或中号小组件，点击阅读对应颜色。已有会员直接获得权益。

收藏和搜索免费，tvOS 保留现有浏览功能。小组件按本地公历日期取色，2 月 29 日沿用 2 月 28 日；实际刷新时间由系统决定。开发与验收记录见 [v1.2.0 发布记录](docs/RELEASE_1_2_0.md)。

有什么需求，欢迎提交PR。

## 隐私政策
本 App 的颜色浏览、选择和收藏记录保存在本地，不同步至 iCloud。搜索在本机完成。会员功能使用 Apple App Store 与 RevenueCat 服务；启动时的会员验证、购买与恢复购买会联网，RevenueCat 会处理匿名用户标识及购买记录，以验证和维护会员权益。App 通过本机 App Group 向小组件共享最近有效的会员状态，小组件不接入购买服务。详情参见 [RevenueCat 隐私政策](https://www.revenuecat.com/privacy/)。
